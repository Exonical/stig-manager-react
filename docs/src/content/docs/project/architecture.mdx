## The Go binary

A single, statically linked binary (`stigman`) is the only application
component. It:

- Serves `/api/*` (REST, JSON, JWT-authenticated).
- Serves `/op/*` (operational endpoints + SSE + WebSocket).
- Serves the **embedded React SPA** at `/` (via `embed.FS`).
- Serves the **embedded Starlight docs** at `/docs/*`.
- Runs an in-process **job scheduler** (leader-elected via a Postgres
  advisory lock).
- Runs **migrations** at startup (`pressly/goose`).

All configuration comes from environment variables.

## The React SPA

React 19 + Vite + TypeScript. Built with:

- **shadcn/ui** for accessible, low-overhead UI primitives.
- **TanStack Router** for typed, file-based routing.
- **TanStack Query** for server state, pagination, and optimistic updates.
- **TanStack Table & Virtual** for the large grids.
- **oidc-client-ts** for the PKCE flow.
- **React Hook Form + Zod** for forms.

## The docs site

Astro Starlight (`docs/`). Built to static HTML/CSS, embedded into the Go
binary at build time and served at `/docs/*`. The OpenAPI v1 spec is
rendered inline via [starlight-openapi](https://github.com/HiDeoo/starlight-openapi).

## Postgres data model

The schema is the synthesised end-state of upstream's 47 MySQL migrations,
translated to Postgres types. The key entities:

```
collection ─┬─< asset ───< asset_stig >─── benchmark ──< revision ──< rule
            │                                            │
            ├─< grant >── user_or_user_group             ├─< check_content
            ├─< label  >── asset_label                   ├─< fix_text
            └─< setting                                  └─< cci_ref, control_map

review (asset_id, rule_id, result, detail, comment, status, history…)

audit_log  job  job_run  job_task  rule_check_content_hash
```

See `api/migrations/0001_baseline.sql` for the authoritative definition.

## Build and packaging

A multi-stage [OCI Containerfile](https://github.com/opencontainers/image-spec)
(built with Docker, Podman, or Buildah):

1. Build the SPA with `pnpm --filter web build` → `web/dist`.
2. Build the docs with `pnpm --filter docs build` → `docs/dist`.
3. Copy both into the Go build context and `go build` with
   `-ldflags="-s -w"` and CGO disabled.
4. Final image: `gcr.io/distroless/static-debian12:nonroot` with the
   binary at `/stigman`.

The resulting image is ~60 MB and runs as a non-root user.

## Why this stack

- **Go** — single static binary, easy to deploy in air-gapped sites, fast
  enough that we don't need a separate worker for imports or exports.
- **Postgres 18** — strict types (`jsonb`, `numeric`, generated columns),
  excellent operational tooling, ubiquitous in restricted environments.
- **React 19 + shadcn/ui** — modern, accessible, themeable, no heavy
  component library.
- **TanStack Router/Query/Table** — strongly-typed, server-driven grids
  with virtualisation; ideal for the multi-thousand-row review grids that
  STIG Manager regularly produces.
