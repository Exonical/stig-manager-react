## Upstream

- [NUWCDIVNPT/stig-manager](https://github.com/NUWCDIVNPT/stig-manager)

  MySQL.
- [Upstream documentation](https://stig-manager.readthedocs.io/en/latest/) —
  reference for concepts and features. This site is the source of truth for
  this implementation.

## Useful upstream clients and utilities

These work unchanged with this implementation (the `/api/v1` surface is
byte-compatible):

- [NUWCDIVNPT/stigman-watcher](https://github.com/NUWCDIVNPT/stigman-watcher)
  — Node.js CLI that watches a directory for `.ckl` / XCCDF files and
  imports them into a Collection.
- [NUWCDIVNPT/stig-manager-client-modules](https://github.com/NUWCDIVNPT/stig-manager-client-modules)
  — JavaScript modules with reference parsers (`reviewsFromCkl`,
  `reviewsFromCklb`, `reviewsFromXccdf`) and a `TaskObject` helper for
  building import payloads.
- [NUWCDIVNPT/stigman-orchestration](https://github.com/NUWCDIVNPT/stigman-orchestration)
  — sample CAC + nginx + Keycloak orchestration for upstream.
