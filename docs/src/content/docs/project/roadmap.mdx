This page is a high-signal view of the **milestones** for reaching upstream
v1.6.10 feature parity. Each item is one or more pull requests against
[`Exonical/stig-manager-react`](https://github.com/Exonical/stig-manager-react).

The order is intentional: the docs site lands first so we always have a
public spec to point at; everything else lands behind it.

## Post-v1 ideas

- Live per-Collection SSE / WebSocket so concurrent evaluators see each
  other's saves.
- Optional object-storage backend for attachments (S3, MinIO, Azure
  Blob).
- A small Go CLI client (`stigmanctl`).
- Helm chart with operator-style migrations.
- Iron Bank delivery.
